# SOP Guidance Skill

PlanSteps:
- confirm equipment state
- list pre-operation safety checks
- map evidence into inspection steps
- add stop conditions
- run compliance_check
- record final SOP in TraceStore

Tools:
- manual_lookup
- compliance_check
- TraceStore

Failure handling:
- if evidence is weak, produce a preliminary SOP and mark it as unverified
- if compliance check fails, revise before delivery

Evidence requirements:
- each risky action should be supported by manual evidence or marked for review
